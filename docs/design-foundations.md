# Design Foundations

These principles guide automatic design decisions inside the blackbox.

## 1. Visual hierarchy

The design must clearly control what is seen first, second, and later.

Typical hierarchy:
1. Main focal point / headline
2. Key message
3. Supporting information
4. Details
5. CTA / source / footer

Hierarchy may be created through:
- scale
- contrast
- weight
- color
- position
- spacing
- imagery

## 2. Gestalt principles

Use where appropriate:

### Proximity
Related elements should be spatially grouped.

### Similarity
Elements with the same function should share visual language.

### Continuity
Use alignment and directional cues to guide reading flow.

### Figure–Ground
Primary subjects and important text must remain visually separable from the background.

### Common Region / Connectedness
Use containers, panels, lines, or shared regions to communicate grouping.

## 3. Grid systems

Use an invisible structural grid rather than arbitrary placement.

The grid should respond to:
- canvas ratio
- information density
- number of content modules
- hero image shape
- reading direction

## 4. Negative space

Whitespace is an active design element, not unused space.

Use it to:
- separate groups
- increase emphasis
- improve readability
- create premium visual rhythm

## 5. Balance

Possible strategies:
- symmetrical
- asymmetrical
- radial
- dynamic

Select based on communication goal and tone.

## 6. Contrast

Consider more than color:
- size
- weight
- shape
- texture
- space
- direction
- luminance

## 7. Typography

Typography should establish clear levels:
- H1 / headline
- H2 / subheadline
- key number / statistic
- body
- caption
- CTA

For Thai text:
- preserve legibility
- avoid collisions with vowels and tone marks
- use appropriate line spacing
- prevent awkward word wrapping
- control headline line count

## 8. Color architecture

Treat colors by function:
- primary
- secondary
- accent
- background
- surface
- text primary
- text secondary
- highlight
- alert

## 9. Information density

Suggested conceptual levels:
- LOW: campaign poster
- MEDIUM: general infographic
- HIGH: technical infographic
- VERY HIGH: one-page report

Density should affect module count, whitespace, font scale, and visual hierarchy.

## 10. Viewing context

Design decisions must consider how the work will be consumed:
- wall / distance
- hand-held print
- mobile screen
- desktop
- presentation screen
- social feed

## 11. Section semantics vs layout

Section = semantic purpose.
Layout = physical placement.

Do not assume Header must always be the top strip or Hero must always be centered.

## 12. Background as a layer

Background is not a normal content section.

Recommended model:
- Background Layer
- Foreground Sections
- Overlay / Decorative Layer

This separation is essential for mapping images and controlling depth.
