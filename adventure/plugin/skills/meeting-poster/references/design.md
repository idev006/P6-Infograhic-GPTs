# Art direction and production
Use reference style when supplied; otherwise elegant navy/royal blue, restrained metallic gold and silver, white paper-like body. Build hierarchy: compact hero/header20–25%, agency/date title10%, table55–65%, operator/footer5–10%. These are adaptable proportions, not fixed clipping boxes. Prefer legible Sarabun/Noto Sans Thai, dark navy text, thin rules, adequate padding. Do not shrink dense weekly schedules below legibility merely to accommodate decoration. Reserve row heights according to wrapped text; calculate total before drawing. If one A4 cannot fit, first reduce decor/header, abbreviate only with permission where meaning changes; report physical limit rather than omit rows silently.

Exact-text production in an executor: use Pillow with RAQM or browser HTML/CSS supporting Thai shaping. Find an installed Thai font or use a supplied licensed font. Compose the original portrait via crop/background removal without altering face/uniform. Generate decorative background via imagegen if useful, then overlay deterministic table and labels. Never use image generation to draw a precise table when a reliable text renderer exists. A reference poster may guide header but its schedule is not data authority. Tools may vary; follow host tool/skill documentation and never invent tool names.

If host imagegen is the only image route, give precise locked data/asset roles, request full framing, then inspect actual output. Retry only targeted errors. Do not guarantee100% portrait or text fidelity. Never output an unverified correction claim.

QC matrix: source rowID → rendered row → date/time/title/owner/chair/room/operator/phone → pass/fail/unverified. Check actual final image at enlarged table crops. Keep matrix internal unless requested. Missing source records, unreadable fields or output mismatch block an unqualified ready-to-send claim. No prior QC status carries forward after edits.
