# Adventure production contract
## Quality gates
Record PASS / FAIL / NOT CHECKED with evidence and artifact version. NOT CHECKED is never PASS.
- Truth: every critical name, date, time, amount, role, location and phone traceable to supplied source; zero invented facts.
- Ambiguity: unreadable OCR values resolved or explicitly marked; never quietly infer digits.
- Content: no missing records/panels, duplicates, accidental reordering or stale amendment.
- Text: compare final visual to canonical copy; zero consequential substitution. Inspect Thai vowel/tone marks and mixed Latin content.
- Layout: zero clipping/overlap; clear hierarchy and adequate contrast. Target body10pt or larger at print size, adapt to purpose. Safe margin5mm as planning default; printer specification overrides.
- Assets: compare hero face/uniform/marks and logo proportions with original. Generated likeness cannot be certified pixel-identical.
- Print: verify actual dimensions, pages, resolution and full decode. Supply bleed only when required (typically3mm, confirm printer); don't claim CMYK/PDF-X/font embedding without inspecting.
- Review: inspect actual final file full page and enlarged dense sections; not an intermediate or prompt.
- Gate: critical data error blocks unqualified release. Correctable issues must be fixed before final delivery. If host tools prevent verification, label unverified draft with exact limitation.

## Regression scenarios
1 Typed schedule: preserve all records and user amendments.
2 Blurry screenshot: mark uncertain critical digits and ask targeted question; no invented answer.
3 Dense Thai/English copy: wrap intact with no clipped marks; shrink decoration before text.
4 Invalid33.00: do not accept as valid time; resolve against source/user13.00.
5 Simultaneous09.00 meetings: separate IDs, no merge.
6 Missing chair: retain — orรอข้อมูล, never invent.
7 New source changes CANVA chair toวิทยากร: replace olderพิษณุ๑.
8 Hero replacement: use actual supplied image, not old generated face.
9 Daily operators differ: preserve date associations and exact phones.
10 Preset invocation changes visual style only, not meeting data.
11 User says don't generate: brief/update only.
12 Public repo documentation: synthetic examples; no private asset uploads.

## Measured maturity
Current release supplies instructions, references, date formatter and schedule validator; it is not a deployed standalone OCR/layout application. Automated text-format checks do not prove image fidelity. Track clean, ambiguous and dense end-to-end fixtures separately; do not mark them passed without actual rendered evidence. Target international professional quality through evidence, not claimed accreditation.
