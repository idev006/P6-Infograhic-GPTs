# Adaptive Collage Engine v0.10

## Purpose

Create sophisticated image-panel compositions that feel balanced to human perception and work with real photos.

## Modes

### BALANCED_MASONRY
Controlled varied image apertures for general activity/report photography.

### PAIRED_BALANCED_MASONRY
A comparison-aware collage for Before/After and paired evidence.

### EDITORIAL_COLLAGE
Magazine/journal composition with stronger dominant/supporting relationships.

## Anti-grid rule

If a collage mode is selected, a uniform equal-size grid is not an acceptable fallback unless explicitly requested.

## Human-perception goals

Optimize for:
- optical balance
- rhythm
- hierarchy
- stable visual mass
- controlled asymmetry
- coherent outer silhouette
- natural eye movement
- useful photo crops

## Dominant/supporting strategy

A strong collage normally has:
- one or more larger anchors
- medium supporting images
- smaller accents only when still readable

Avoid making every image equally dominant.

## Paired comparison

For Before/After:
- pairing must remain obvious
- paired apertures should have comparable crop opportunity
- pair modules may differ in scale across the page
- relationships can be mirrored, aligned, or grouped
- avoid identical row repetition

## Editorial frames

Frame family may use:
- clipped corners
- partial strokes
- subtle matting
- controlled shadow
- theme anchors
- frameless image masks

The frame should support the photo, not dominate it.

## Real-photo rule

Every panel must have a plausible use with a real activity photograph.

If common photos would require destructive crop or become unreadably small, resize/restructure the collage.
