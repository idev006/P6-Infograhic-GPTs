- Background = AUTO-DESIGNED

## Behavior

- Explicit user image_panel_count overrides suggested panel count.
- Explicit Hero disable overrides preset Hero.
- Explicit panel_frame_mode overrides THEMED_FRAME.
- Explicit region source mappings override inferred reference roles.
- Shell styling is selected from content type, institutional context, references, and requested mood.
