# Design Foundations

These principles guide automatic design decisions inside the blackbox.

## Visual hierarchy
Control what is seen first, second, and later:
1. Main focal point / headline
2. Key message
3. Supporting information
4. Details
5. CTA / source / footer

Use scale, contrast, weight, color, position, spacing, and imagery.

## Gestalt principles
- Proximity: group related elements.
- Similarity: same-function elements share visual language.
- Continuity: use alignment/direction to guide reading.
- Figure–Ground: keep subjects/text separable from background.
- Common Region / Connectedness: use panels/lines/regions to show grouping.

## Grid systems
Use an invisible structural grid responsive to canvas ratio, density, module count, hero shape, and reading direction.

## Negative space
Whitespace is an active design element used to separate groups, increase emphasis, improve readability, and create rhythm.

## Balance
Choose symmetrical, asymmetrical, radial, or dynamic balance based on the communication goal.

## Contrast
Consider size, weight, shape, texture, space, direction, and luminance—not only color.

## Typography
Use clear levels:
- H1 / headline
- H2 / subheadline
- key number / statistic
- body
- caption
- CTA

For Thai:
- preserve legibility
- avoid collisions with vowels/tone marks
- use appropriate line spacing
- avoid awkward word wrapping
- control headline line count

## Color architecture
Assign functional roles:
primary, secondary, accent, background, surface, text-primary, text-secondary, highlight, alert.

## Information density
- LOW: campaign poster
- MEDIUM: general infographic
- HIGH: technical infographic
- VERY_HIGH: one-page report

Density affects module count, whitespace, font scale, and decorative complexity.

## Viewing context
Account for wall/distance, hand-held print, mobile, desktop, presentation screen, and social feed.

## Section semantics vs layout
Section = semantic purpose.
Layout = physical placement.

## Background as a layer
Background is not a normal content section. Treat it separately from foreground sections and overlay/decorative layers.
